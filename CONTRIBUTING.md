# Contributing to TORDISSX86

Thank you for your interest in contributing!

## How to contribute

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Make your changes.
5. Test your changes.
6. Commit your changes.
7. Open a Pull Request.

## Development rules

- Write clean and readable Python code.
- Use meaningful variable names.
- Document new modules.
- Test features before submitting.
- Do not commit passwords, tokens or private data.
- Respect privacy and applicable laws.

## Bug reports

Include:
- Description of the issue.
- Steps to reproduce it.
- Expected behavior.
- Actual behavior.
- Relevant error messages.

Thank you for helping improve TORDISSX86!
