# Security Policy

TORDISSX86 takes responsible security reporting seriously.

## Reporting vulnerabilities

Please report security issues privately to the project maintainer.

Do not publish:
- API keys
- Authentication tokens
- Passwords
- Private investigation records
- Personal information

## Responsible use

Only investigate systems and information you are authorized to access.

Do not use this project for unauthorized access, harassment or privacy violations.

## Supported versions

The latest published version is the primary version considered for security updates.
