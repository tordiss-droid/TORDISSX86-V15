## About

TORDISSX86 is an OSINT and cybersecurity learning project designed to bring multiple information-analysis tools together in one interface.

The project is developed under the TORDISSX86 brand with a focus on Python, cybersecurity education, digital investigation and information analysis.

## Installation

### 1. Install Termux packages

```bash
pkg update && pkg upgrade -y
pkg install python git -y
```

### 2. Clone the repository

```bash
git clone https://github.com/tordiss-droid/TORDISSX86_OPEN-SOURCE-INTELLIGENCE-OSINT-.git
```

### 3. Enter the project

```bash
cd TORDISSX86_OPEN-SOURCE-INTELLIGENCE-OSINT-
```

### 4. Install dependencies

If requirements.txt exists:

```bash
pip install -r requirements.txt
```

### 5. Start the application

Check the project documentation and application entry point before starting the dashboard.
